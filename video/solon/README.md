# Солон: минималистичное видео (Remotion)

Короткий ролик (~94 с, 1920×1080, 30 fps) по презентации «Солон: автономный агент для досудебных претензий».

```bash
npm install
npm run studio   # предпросмотр
npm run render   # out/solon.mp4
```

Сцены лежат в `src/scenes.tsx`, порядок и длительность в `src/Video.tsx` (`TIMELINE`), общие компоненты (карточки, стрелки, заголовки) в `src/ui.tsx`.
